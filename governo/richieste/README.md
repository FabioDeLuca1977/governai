# Domande al Consiglio dei ministri

Ogni file `.md` in questa cartella è una domanda al Consiglio. La prima riga è il titolo. Il Consiglio la esamina alla prima esecuzione dell'attività quotidiana. Quando la seduta è chiusa, il file viene spostato in `fatte/`.

Le domande arrivano in tre modi:
- **dai cittadini**, con il modulo "Domanda al Consiglio" sul sito. Un membro del progetto la legge e, se la approva, applica l'etichetta `analisi-approvata`;
- **dai membri del progetto**, con un file scritto direttamente qui, partendo da `_modello.md`;
- **in chat**, chiedendolo a Claude.

Per una domanda che riguarda pochi ministeri, scrivi nella riga `Ministri:` i numeri delle aree (per esempio `01, 06`). Se la lasci vuota, il Consiglio si riunisce al completo.
